# **Reqs funcionales**

| Código | Nombre | Requisito |
| :---- | :---- | :---- |
| RF01 | Presentación de recomendaciones | El sistema deberá presentar al usuario una lista diaria personalizada con un máximo de 10 artículos recomendados. |
| RF02 | Registro de áreas de interés | El producto de software deberá permitir al usuario registrar una o varias áreas de interés científico para personalizar el contenido mostrado. |
| RF03 | Modificación de áreas de interés | El producto de software deberá permitir al usuario modificar sus áreas de interés en cualquier momento. |
| RF04 | Categorías de áreas de interés | El producto de software deberá definir una cantidad predeterminada de categorías de áreas de interés. |
| RF05 | Consulta periódica de fuentes | El sistema debe ser capaz de sincronizar, almacenar y categorizar diariamente las nuevas publicaciones indexadas en el repositorio abierto de ArXiv  |
| RF07 | Acceso al artículo original | El producto de software deberá permitir acceder al artículo científico original desde la plataforma. |
| RF10 | Publicaciones relacionadas | El producto de software deberá ofrecer al usuario una lista de publicaciones relacionadas con una publicación consultada para facilitar el descubrimiento de contenido afín sin requerir una búsqueda explícita. |
