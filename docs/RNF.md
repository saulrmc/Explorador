# **Reqs no funcionales**

| Código | Categoría | Descripción |
| :---- | :---- | :---- |
| RNF01 | Usabilidad | El software deberá notificar al usuario sin la necesidad de que esté ejecutándose en primer plano. |
| RNF02 | Rendimiento | El software en ejecución deberá percatarse de la publicación de un nuevo artículo como máximo con un minuto de retraso |
| RNF03 | Rendimiento | El software deberá soportar procesar al menos 100  publicaciones diarias en un estado regular de funcionamiento. |
| RNF04 | Protección contra errores del usuario | El software debe prevenir los intentos de cambios destructivos solicitando una confirmación antes de realizar un cambio destructivo. Estos cambios destructivos incluyen borrar publicaciones guardadas y borrar el historial de publicaciones consultadas |
| RNF05 | Utilización de recursos | En su versión inicial el software debe ser implementado por tecnologías libres o de código abierto y en infraestructura existente, de manera que no se necesiten licencias de software ni hardware adicional. |
| RNF06 | Modularidad | El software debe tener tareas claramente definidas y repartidas entre sus componentes, de manera que cada componente realice una tarea principal y sus dependencias con otros componentes estén delimitadas |
| RNF07 | Capacidad de ser modificado | El desarrollo e implementación de modificaciones del software debe requerir un cambio en un único módulo o en un conjunto reducido de módulos, minimizando el impacto sobre el resto del sistema |
